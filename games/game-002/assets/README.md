# Assets

Store game-specific source assets and a small manifest here. Follow [the art style bible](../../../agent-instructions/art-style-bible.md). Prompt drafts are in `../assets-needed.md`; Snow generates or supplies final artwork.

For every imported asset, record filename, purpose, source/creator, usage rights, Roblox asset ID, and import date. Use PENDING for missing facts. Do not commit secrets, unlicensed assets, or large generated build files.

No external artwork has been generated or imported. Native text/glyph UI implements the core loop; finalized optional listing/effect prompts are in ../assets-needed.md.
