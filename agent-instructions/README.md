# Agent handbook

The canonical rules are in [AGENTS.md](../AGENTS.md). This folder explains how to apply them; it does not replace them.

- [Session checklist](session-checklist.md): resume work and leave a useful checkpoint.
- [Definition of done](definition-of-done.md): development, playtest, and release gates.
- [Art style bible](art-style-bible.md): starter visual guidance and unresolved preferences.

Read `factory-state/` first, then the active game's spec and checkpoint. Load only knowledge entries relevant to the task. An empty queue is a request for Snow's next idea, not permission to invent one.

Keep systems small. Changes to shared systems must preserve the pinned behavior of older games. Record decisions and evidence in the relevant game instead of expanding the handbook with speculative rules.
