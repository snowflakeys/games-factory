# Idea Catalog (40 concepts)

Rank = position in the report's weighted scorecard (see `greenlight-checklist.md` for the formula). Scores are design estimates, not player data. "Home" is the report's release suggestion: **S** = standalone experience, **P** = Party Lab bundle, **-** = undecided.

Multiplayer population notes: simultaneous-choice games scale 2-12 with no extra turns; sequential tabletop games should cap tables at 4-6 and run parallel tables above that.

## Reading the catalog

- Top five by score: Don't Match Me, Screen Collapse, Rule Stack, Alien Customs Desk, Last Safe Number. Next five: Copycat Trap, Rules Are Auctioned, Fake Timer, Count Without Counting, Human Loading Bar.
- Cheapest to prototype: Last Safe Number, Fake Timer (1 day), Receipt Detective, Count Without Counting, Button Budget (1-2 days).
- Highest technical risk: Shared Cursor, Contradiction Protocol, Human Loading Bar, Freeze Frame.
- Build-time estimates are engineering judgment, not evidence. "Prototype" is often much faster than "MVP", which includes integration and mobile/edge-case testing.
